# Where to put your photos

Drop real photos into these folders using the EXACT filenames below.
The site already references these paths, so images appear automatically —
no code changes needed. Until a file exists, that spot shows a clean
dashed placeholder with a label instead of a broken image icon.

## /images/categories/  (used on the category picker — Home + Dine In + Delivery)
Square photos work best (the tile crops to a square). Roughly 800x800px.
- shrimp.jpg
- fillet.jpg
- crab.jpg
- calamari.jpg
- burger.jpg
- platters-single.jpg
- platters-family.jpg
- grilled-jumbo.jpg

## /images/products/  (used on the homepage "showcase" sections)
Portrait photos work best (4:5 ratio). Roughly 900x1125px.
- classic-shrimp.jpg
- shrimp-burger.jpg
- shrimponi-fillet.jpg

## /images/hero/  (floating decorative shrimp on the homepage hero)
One image, ideally a PNG with a transparent background (a cut-out shrimp
photo), roughly 400x400px minimum. It's reused multiple times at different
sizes to create the floating effect.
- shrimp.png
